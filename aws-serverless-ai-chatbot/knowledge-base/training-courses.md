# Training Courses
CloudAssist Academy offers the following sample courses:

## AWS Cloud Practitioner Foundations
Audience: beginners. Duration: 4 weeks. Prerequisites: none. Topics: cloud concepts, AWS core services, security, pricing, and billing.

## AWS Solutions Architect Associate Preparation
Audience: learners with basic AWS familiarity. Duration: 6 weeks. Topics: VPC, EC2, S3, IAM, high availability, resilience, and cost optimization. Certification exam registration is separate.

## AWS Serverless Development
Audience: developers with basic programming skills. Duration: 4 weeks. Topics: Lambda, API Gateway, DynamoDB, event-driven design, and observability.

Schedules and fees are not fixed in this demo; request the current schedule from an authorized training representative.
